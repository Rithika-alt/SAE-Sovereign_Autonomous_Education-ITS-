# Sovereign Autonomous Education (SAE) System

The SAE System is a multi-agent AI tutoring platform that runs entirely locally using Ollama. It combines a LangGraph orchestration layer, semantic response grading, an adaptive knowledge graph, anti-malpractice verification, tamper-evident proof-of-learning hashes, and a Streamlit dashboard — all without sending any data outside the local machine.

---

## Prerequisites

- **Python 3.10+**
- **Ollama** installed and running — https://ollama.ai
- `llama3.2` model pulled:
  ```bash
  ollama pull llama3.2
  ```

---

## Installation

```bash
# 1. Clone the repository
git clone <repo-url>
cd sae_system

# 2. Install Python dependencies
pip install -r requirements.txt

# 3. Configure environment variables
cp .env.example .env
# Edit .env if needed (defaults work out of the box with Ollama on localhost)
```

---

## Running the CLI

```bash
python main.py --student_id alice --concept_id neural_networks --domain machine_learning
```

**Arguments:**

| Flag | Default | Description |
|---|---|---|
| `--student_id` | `student_01` | Learner identifier |
| `--concept_id` | `linear_algebra` | Starting concept node |
| `--domain` | `machine_learning` | Subject domain |

---

## Running the Dashboard

```bash
streamlit run dashboard/app.py
```

Open your browser at `http://localhost:8501`.

## Architecture Overview

| Component | Module | Purpose |
|---|---|---|
| `student_id` | `state_schema.py` | Learner identifier |
| `concept_id` | `state_schema.py` | Current concept being studied |
| `domain` | `state_schema.py` | Subject domain |
| `lesson_content` | `tutor_agent.py` | Lesson text generated by the tutor LLM |
| `student_response` | `state_schema.py` | Student's free-text answer |
| `reference_answer` | `state_schema.py` | Ground-truth reference for grading |
| `semantic_score` | `semantic_auditor.py` | Cosine similarity score [0–1] |
| `logic_score` | `anti_malpractice.py` | Reasoning verification score [0–1] |
| `composite_score` | `auditor_agent.py` | Weighted composite (0.7 sem + 0.3 logic) |
| `mastery_level` | `graph_engine.py` | Per-concept mastery [0–1] |
| `cognitive_load_score` | `affective_pacing.py` | Rolling mean entropy of responses |
| `response_history` | `state_schema.py` | Last 3 student responses |
| `current_phase` | `state_graph.py` | lesson / audit / clarification / retry / complete |
| `session_id` | `main.py` | UUID per session |
| `error_message` | All agents | Graceful error propagation |
| `next_concept_id` | `graph_engine.py` | Next recommended concept |
| `proof_hash` | `proof_of_learning.py` | SHA-256 mastery receipt |

## Sovereignty Note

All LLM inference runs locally via Ollama at `http://localhost:11434`. No student data, responses, or lesson content are transmitted outside the local machine. The `SovereigntyError` exception is raised if `OLLAMA_BASE_URL` is set to a non-localhost address, enforcing this guarantee at runtime.
